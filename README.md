# 🎨 AI 繪圖快速指令大全 (Interactive Web)

這是一個互動式網頁應用程式，彙整了各種實用的 AI 繪圖指令，並自動提供範例預覽與一鍵複製功能。

## 🌟 功能特色
1. **指令視覺化**：為每一個繪圖指令動態生成一張範例圖片（包含模擬上傳修改的圖片）。
2. **一鍵複製**：提供專屬按鈕，輕鬆複製「指令」或「提示詞內容」。
3. **即時檢索**：強大的搜尋列，可透過指令名稱或中文描述快速尋找所需功能。
4. **精美 UI**：明亮色彩、大字體設計、豐富的圖示（FontAwesome）以及順暢的動畫。
5. **互動音效**：點擊按鈕複製時，會播放精緻的 UI 互動音效與成功提示音。

## 📂 檔案架構
```text
drawing-commands-web/
├── index.html   # 首頁結構與佈局
├── style.css    # 樣式表、色彩主題與動畫
├── script.js    # 互動邏輯、搜尋功能與圖片載入
└── README.md    # 專案說明文件
```

## 🚀 如何使用
1. 直接用瀏覽器開啟 `index.html` 即可使用。
2. 網頁載入時，會自動透過 AI 圖像服務生成對應的範例縮圖，請確保處於連線狀態。
3. 在上方搜尋列輸入關鍵字過濾指令。
4. 點擊「複製指令」獲取 `/headshot` 等短指令；點擊「複製提示詞」獲取對應的中文描述說明。

## 🛠 技術堆疊
- **HTML5**
- **CSS3** (CSS Variables, Flexbox/Grid, Animations)
- **Vanilla JavaScript** (DOM Manipulation, Clipboard API)
- **Pollinations.ai** (自動產生範例圖像)
- **FontAwesome** (向量圖示)
